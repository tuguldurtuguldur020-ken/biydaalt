# PlateWatch — Автомашины дугаар танигч

Дан Python desktop програм: **Tkinter + Ultralytics YOLO + EasyOCR (mn, en) + OpenCV**.
Зураг, видео болон USB/webcam камераас Монголын түгээмэл **4 цифр + 3 кирилл үсэг** бүхий дугаар уншина.
Өгөгдөл нь CSV, JSON, JPEG файлд хадгалагдана. Вэб frontend/backend, SQL болон сервер суулгах шаардлагагүй.

## Шууд ажиллуулах

Камераа шууд асаах бол **`camera.bat`**-ийг давхар товшино. Камерыг автоматаар олно; ажиллахгүй хуучин индекс сонгогдсон байсан ч байгаа төхөөрөмж рүү шилжинэ.
Одоогийн Python хувилбар **2.3.0**. Дүрс зурах үед санах ойн алдаа гарч камер, зураг импортлох шинэчлэлт зогсдог байсныг зассан. Алдаа гарвал давталт үргэлжилж, зургийг багасган дахин зурна.

1. Энэ хавтас дахь **`run.bat`** файлыг давхар товшино. VS Code нээх шаардлагагүй.
2. **Зураг импортлох**, **Видео импортлох**, эсвэл камерын индексээ сонгоод **Камер** дээр дарна.
3. Дугаар танигдмагц баруун самбарт дугаар, OCR/YOLO итгэлцүүр, хязгаарлалтын төлөв гарна.
4. Бүртгэл дээр давхар товшиж бүтэн зураг, дугаарын хэсэг, JSON мэдээллийг нээнэ.

Windows 10/11, 64-bit **Python 3.11–3.13** хэрэгтэй. Python 3.15 сонгохгүй.
Анхны эхлэлт `.venv` үүсгэн шаардлагатай сангууд суулгана. Бэлэн сан байвал дахин суулгахгүй.
Шинэ компьютер дээр сан, YOLO болон OCR жин татахад интернэт, хэдэн минут болон ойролцоогоор 1–2 GB сул зай шаардагдаж болно.
Жин татагдсаны дараа танилт **локал**, интернэтгүй ажиллана. Зураг/бичлэгийг серверт илгээхгүй.

Камерын сонголтыг **Авто** дээр тавиад **Камер** дарна. Илэрсэн бодит төхөөрөмжийн индексийг програм өөрөө харуулна.
Камер огт олдохгүй бол Windows Settings → Privacy & security → Camera → desktop apps тохиргоог шалгаж, камер ашиглаж буй бусад програмыг хаана.

## Боломжууд

- Зураг сонгомогц, камер нээгдмэгц дүрс шууд гарна; AI ачаалж дуустал хар дэлгэц хүлээхгүй.
- Камер ажиллаж байхад зураг/видео сонговол өмнөх ажлыг зогсоож автоматаар шилжинэ.
- Файл сонгох цонхоос гадна зүүн талын замын талбарт файлын бүтэн замыг хуулж **Нээх** дарж болно.
- Нэг төслөөс давхар GUI нээж камерыг булаалдахгүй; дахин ажиллуулбал нээлттэй цонхоо гаргана.
- Нэг болон олон зураг импортлох, MP4/AVI/MOV/MKV видео нээх.
- Камерын дүрсийг тусдаа thread-ээр авч, GUI гацаахгүйгээр AI танилт хийх.
- Видео/камерын дугаарыг анхдагчаар **2 удаагийн уншилтаар баталгаажуулах**.
- Ижил дугаарыг анхдагчаар **20 секунд** тутмаас ойр давтаж хадгалахгүй; зураг бүр тусдаа хадгалагдана.
- Бүтэн кадрт хүрээ, кирилл дугаар зурах; дугаарын crop, цагтай JSON, CSV бүртгэл хадгалах.
- Түр зогсоох, үргэлжлүүлэх, бүрэн зогсоох, гараар кадр хадгалах.
- Хүсвэл боловсруулсан видеог MP4 болгон хадгалах.
- Дугаар, огноо, хязгаарлалтын төлвөөр хайх; Excel-д нээгдэх UTF-8 CSV экспортлох.
- Өнөөдрийн нийт илрэлт, ялгаатай дугаар, хуваариар хязгаарлалттай илрэлтийн тоо.
- Үндсэн өнгийг цэнхэр, ногоон, нил ягаан, ягаан болгох; OCR/YOLO босго, видео кадрын алхам, давталтын зайг өөрчлөх.
- `Ctrl+O`: зураг импортлох; `Ctrl+S`: кадр хадгалах; `Esc`: зогсоох.

## Хадгалалтын бүтэц

```text
data/
  settings.json              # GUI тохиргоо
  detections.csv             # Дугаар, цаг, эх үүсвэр, итгэлцүүр, хуваарь, зургийн зам
  app.log                    # Алдааны дэлгэрэнгүй
  evidence/YYYY-MM-DD/
    ..._1234УБА.jpg           # Хүрээ, дугаартай бүтэн кадр
    ..._1234УБА_plate.jpg     # Дугаарын хэсэг
    ..._1234УБА.json          # Бүртгэл, OCR raw text, bbox, хуваарийн үр дүн
  snapshots/                 # Гараар хадгалсан кадр
  videos/                    # Сонголтоор хадгалсан MP4
  models/ocr/                # EasyOCR-ийн татсан жин
  models/plate_detector.pt   # Анх хэрэглэхэд татах бэлэн YOLO detector
models/
  mongolian_best.pt          # Өөрийн өгөгдлөөр сургасны дараах жин
```

Цагийг компьютерын timezone-оос үл хамааран **Улаанбаатар UTC+08:00**-аар бүртгэнэ.
Видео дахь кадрын байрлалыг `video_seconds` баганад хадгална. Импортын `detected_at` нь боловсруулах үеийн цаг;
эх бичлэгийн бодит авсан огноо гэж үзэхгүй. JSON дахь `time_basis` үүнийг ялгана.
Хадгалалтын хавтсыг өөрчлөхөд `PLATEWATCH_DATA_DIR` environment variable ашиглаж болно.

## Тухайн өдөр зорчих эсэх

**Хязгаарлалт** цэсэнд `1113` шиг зөвхөн 4 цифр эсвэл `1113УБА` шиг бүтэн дугаар оруулж болно.
Гол үр дүнд хязгаарлах өдөр болон зорчих өдрүүд шууд гарна: анхдагч хуваариар **1113 → Лхагва**.
Огноо, цаг оруулаад **Явах өдрийг харуулах** дарвал сонгосон тухайн өдрийн төлөвийг тусдаа мөрөнд харуулна.
Жишээлбэл `2026-11-13` нь Баасан боловч 1113-ын хязгаарлах өдөр нь Лхагва хэвээр байна.
Сүүлийн цифрийг `1234УБА` дугаарын **4** гэсэн тооноос авна.

Анхдагч жишиг хуваарь: Даваа 1/6, Мягмар 2/7, Лхагва 3/8, Пүрэв 4/9, Баасан 5/0; 08:00–20:00.
Үүний суурь эх сурвалж нь [Тээврийн цагдаагийн албаны тайлбар](https://transportation.police.gov.mn/a/4646).
Энэ нь шинэ түр зохицуулалтыг автоматаар татах үйлчилгээ биш. Өдрийн бодит зохицуулалтад тааруулж **Тохиргоо** цэснээс:

- 7 хоногийн хуваарь, тэгш/сондгой, эсвэл унтраалттай горим сонгоно.
- Цагийн хүрээ, өдрүүдийн хязгаарлах цифр, тэгш огнооны дүрмийг тохируулна.
- Эх үүсвэр хязгаарлалтын бүсэд байгаа эсэхийг гараар тэмдэглэнэ.
- Баяр/чөлөөлөх өдрүүдийг `2026-11-26, 2026-12-29` хэлбэрээр нэмнэ.
- Чөлөөлөх дугаарыг `1234УБА, 5678УБВ` хэлбэрээр нэмнэ.

Төлөв бол **тохируулсан хуваарийн тооцоо**, албан ёсны зөрчил/торгуулийн шийдвэр биш.
Бүртгэлд илрээгүй нь машин тухайн өдөр огт яваагүй гэсэн баталгаа болохгүй.
Бодит байршил, нийтийн амралтын өдрүүд болон тусгай зөвшөөрлийг автоматаар тодорхойлохгүй.

## Монгол өгөгдлөөр fine-tune хийх

Оруулсан detector нь [Koushim-ийн YOLOv8n дугаар илрүүлэгч](https://huggingface.co/Koushim/yolov8-license-plate-detection).
Татахдаа тогтмол revision, SHA-256 шалгана. Монгол өгөгдлөөр сургасан, үнэлсэн гэж тооцохгүй.
EasyOCR-ийн [дэмждэг хэлний жагсаалтад](https://jaided.ai/easyocr/) Монгол `mn` багтдаг.
Бодит танилт нь дугаарын хэмжээ, фокус, гэрэл, өнцөг болон Монгол өгөгдлийн чанараас хамаарна.
Тусгай/дипломат/мотоциклын өөр формат энэ хувилбарын 4+3 шалгалтаар бүртгэгдэхгүй.

1. [Roboflow Universe License Plate Recognition](https://universe.roboflow.com/roboflow-universe-projects/license-plate-recognition-rxg4e) өгөгдлийг **YOLO** форматаар экспортолно.
2. Монгол дугаарын өдөр/шөнө, өөр өөр өнцөг, цаг агаартай зураг нэмнэ. Label Studio эсвэл CVAT-д дугаарын хүрээг `license_plate` class-аар тэмдэглэнэ.
3. Бүх зураг дээр нэг class-ийн ID `0` ашиглана. Frame-ээр бус, нэг автомашин/бичлэгээр train/validation/test-ийг салгаж өгөгдөл давхцахаас сэргийлнэ.
4. Экспортын `data.yaml` замаа ашиглан дараах командыг ажиллуулна:

```bat
.venv\Scripts\python.exe train.py --data datasets\mongolian_plates\data.yaml --epochs 80 --device cpu
```

CUDA суусан NVIDIA GPU-тэй бол `--device 0` хэрэглэж болно.
Сургасан жин `models/mongolian_best.pt` болно. **Тохиргоо → Өөрийн YOLO .pt → Сонгох → Тохиргоо хадгалах**.
Бэлэн жингийн сонголтод буцахдаа model замыг хоосолно.
Өгөгдлийн болон Ultralytics/EasyOCR/моделийн лиценз эх үүсвэртээ үйлчилнэ.

## EXE бүтээх

v2.2.0 нь зураг дээрх тасалдсан дугаарын хүрээг нөхөж унших, MNG/MGL тэмдгийг ялгах, 1113-ын гарагийг зөв тусад нь харуулах засваруудтай.
Бэлэн багцын эхлэх файл: `dist/PlateWatch/PlateWatch.exe`. Хувилбар нь тухайн хавтасны `VERSION.txt` болон цонхны гарчигт гарна.
Windows Application Control гарын үсэггүй EXE-г хориглосон тохиолдолд энэ компьютер дээр шалгаж ажиллуулсан **`run.bat`** хувилбарыг ашиглана.
Энэ хавтаст байгаа EXE нь өмнөх **2.2.0** хувилбар бөгөөд 2.3.0-ийн камер/зураг шинэчлэх засварыг агуулаагүй. Түүнийг ажиллуулахад Windows `4551` хориг өгсөн тул frozen GUI/AI runtime энд шалгагдаагүй; дэлгэрэнгүй нь `test_artifacts/exe_verification_2_2.json`-д бий. Шинэ засварыг **үндсэн хавтасны `run.bat` эсвэл `camera.bat`**-аар ажиллуулна.
Системийн хамгаалалтын тохиргоог програм өөрчлөхгүй.

`build_exe.bat`-ийг давхар товшино. PyInstaller сууж, `dist/PlateWatch/PlateWatch.exe` үүснэ.
EXE-г дамжуулахдаа **`dist/PlateWatch` хавтсыг бүтнээр нь** хуулна; `_internal` болон `models` нь хамт байх ёстой.
OCR жинг урьдчилан **Тохиргоо → AI загвар бэлтгэх / шалгах** үйлдлээр татвал build дотор хуулна.
EXE build нь том хэмжээтэй; `.bat` ажиллахад EXE шаардлагагүй.

## Шалгах

```bat
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\python.exe biydaalt.py --smoke-test
.venv\Scripts\python.exe setup_models.py
.venv\Scripts\python.exe biydaalt.py --verify-image test_artifacts\synthetic_car.png --report test_artifacts\python_verification.json
```

Тест нь OCR текстийн нэгтгэл, кирилл тэмдэг, 0-оор эхлэх дугаар, хуваарь/цагийн зааг,
CSV/JSON/кирилл замд зураг хадгалалт, давхардал, зураг/видео pipeline болон видео экспорт шалгана.
Бодит OCR нарийвчлалыг өөрийн тэмдэглэгээтэй Монгол test dataset дээр тусад нь үнэлнэ.
v2.3.0-ийн 39 автомат тест тэнцсэн. Санах ойн алдааны дараа камер/зураг дахин харагдах, шинэ кадргүй зураг дахин зурах, Tk зургийг давтан ашиглах, камер → зураг солихыг шалгасан.
Бодит GUI дээр камераас Windows-ийн жинхэнэ файл сонгох цонхоор зураг руу шилжүүлж, туршилтын `1234УБА` дугаарыг унших, хадгалах үйлдлийг шалгасан.
Мөн бодит камер дээр `MemoryError` зориуд үүсгэхэд дүрс сэргэж, дараа нь хэрэглэгчийн сонгосон Toyota зургийг `+ Зураг` товчоор оруулж `9638УЕН` гэж унших, хадгалах үйлдэл тэнцсэн.

```bat
.venv\Scripts\python.exe verify_camera.py --index 0
.venv\Scripts\python.exe verify_native_import.py --camera-first
.venv\Scripts\python.exe verify_native_import.py --camera-first --simulate-render-failure --image "зургийн бүтэн зам.jpg"
```

Эдгээр бодит AI шалгалтыг санах ой хэмнэхийн тулд зэрэг ажиллуулахгүй.
OCR нь YOLO-ийн тайрсан хэсгийг EasyOCR `recognize()`-оор шууд уншдаг; давхар CRAFT/VGG текст илрүүлэгч ачаалахгүй.
Энэ нь анхны ачаалалтын 400+ MB түр давхаргын санах ойн алдааг арилгана. API тайлбар: [EasyOCR documentation](https://www.jaided.ai/easyocr/documentation/).

Хэрэв Windows `WinError 4551` гэж PyTorch DLL хоригловол `data/app.log`-ийг шалгана.
Энэ нь Windows Application Control-ийн хориг; админтайгаа тухайн албан dependency-г шалгуулна.
Python 3.13 CPU хувилбар дахин суулгах шаардлагатай үед [PyTorch-ийн албан зааварт](https://pytorch.org/get-started/previous-versions/) байгаа хос хувилбарын жишээ:

```bat
.venv\Scripts\python.exe -m pip install torch==2.9.1 torchvision==0.24.1 --index-url https://download.pytorch.org/whl/cpu
```
